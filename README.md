# TaisarTownHub

Premium real estate agency website + ERP demo (Taiser Town Scheme 45, Karachi).

## Scripts
- `npm install`
- `npm run dev` — dev server on port 3000
- `npm run lint` — TypeScript check
- `npm run test` — unit tests
- `npm run build` — production build

## Demo mode
Set `VITE_DEMO_MODE=true` in `.env.local` to enable fictional sample data and role simulation.

## Security
See SECURITY_AUDIT.md. No production backend is configured; localStorage is demo-only.
